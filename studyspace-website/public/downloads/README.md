# StudySpace Marketing-Downloads

In diesem Ordner liegen zusätzliche, druckbare Marketing-Dokumente für StudySpace:

- `onepager.html`
- `flyer.html`

Die Dateien sind vollständig eigenständig und können direkt im Browser geöffnet werden. Sie sind für A4-Druck und "Als PDF speichern" optimiert.

## Lokal öffnen

Im Projektordner `studyspace-website` den lokalen Vite-Server starten:

```bash
npm run dev
```

Danach können die Dokumente über diese URLs geöffnet werden:

- http://localhost:5173/downloads/onepager.html
- http://localhost:5173/downloads/flyer.html

Alternativ können die HTML-Dateien auch direkt aus dem Dateisystem im Browser geöffnet werden.
